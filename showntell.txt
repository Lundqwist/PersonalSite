SHOW & TELL — How the CV gets from the database to the website
================================================================

The journey of one CV entry, step by step, in the order the data travels:

   MariaDB table "CvEntries"
        │  (1) connection set up in Program.cs
        ▼
   CvEntry model + AppDbContext          (2) the table as C# objects
        │
        ▼
   CvController.Index()                  (3) reads + groups the entries
        │  View(grouped)
        ▼
   Views/CV/Index.cshtml                 (4) turns them into HTML cards
        │
        ▼
   https://lundqwist.se/CV               (5) what the visitor sees

Every step below says FILE:LINE so you can jump straight to it.
(In VS Code: Ctrl+P, type the file name, then ":" and the line number,
 e.g.  Controllers/CvController.cs:34 )

Controllers/CvController.cs:29-48   — runs when someone opens /CV
    public async Task<IActionResult> Index()
    {
        var entries = await _db.CvEntries        // line 34
            .OrderBy(e => e.Type)                // line 35
            .ThenBy(e => e.SortOrder)            // line 36
            .ToListAsync();                      // line 37  <- the database is asked HERE

        var grouped = entries                    // line 42
            .GroupBy(e => e.Type)
            .ToDictionary(g => g.Key, g => g.ToList());

        return View(grouped);                    // line 47  <- hands the data to the view
    }

  • Lines 34-37: EF Core turns this into SQL, roughly
        SELECT * FROM CvEntries ORDER BY Type, SortOrder
  • Lines 42-44: groups the rows into a dictionary:
        { Workplace: [...], Course: [...], School: [...], Board: [...] }
  • Line 47: View(grouped) sends that dictionary to Views/CV/Index.cshtml,
    where it is called "Model".
